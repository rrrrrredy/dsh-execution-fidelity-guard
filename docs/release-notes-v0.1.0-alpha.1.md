# v0.1.0-alpha.1

First public alpha of the buildless DeepSeek Harness adapter for Execution Fidelity Guard.

Validated surfaces include deterministic pre-tool policy, native ask mapping, immutable result evidence, bounded turn-stopping verification, argument-redacted receipts, packaged execution, and a six-job operating-system/Node matrix.

Compatibility is pinned to DeepSeek Harness `v0.1.2-alpha.2`. This release is a prerelease because upstream APIs remain in developer preview and online efficacy evidence is not yet available.
